# 🧩 Dynamic Programming — Start Here!
## Topic Kya Hai?
DP mein **overlapping subproblems** ko solve karke results store karte hain (memoize) taaki dobara compute na karna pade. **Recursion + Memoization = DP**.
## 📊 Interview Importance: 🔴 90% interviews — HARDEST BUT MOST ASKED!
## ⏱️ Estimated Time: **4 days (12-16 hours)**
## 🎯 Kya Seekhna Hai?
1. Memoization (Top-Down) vs Tabulation (Bottom-Up)
2. 1D DP: Fibonacci, Climbing Stairs, House Robber
3. 2D DP: LCS, Edit Distance, Grid problems
4. Knapsack pattern: 0/1 Knapsack, Coin Change
5. LIS (Longest Increasing Subsequence)
