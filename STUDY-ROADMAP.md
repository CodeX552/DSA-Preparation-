## 💡 Pro Tips

1. **Pehle samjho, phir likho** — Copy-paste se kuch nahi hoga
2. **Har problem ka pattern note karo** — Patterns repeat hote hain
3. **Dry run pen-paper pe karo** — Code likhne se pehle logic clear karo
4. **Edge cases pehle socho** — Interviewer impress hoga
5. **Ek hi topic mein 2 din se zyada mat ruko** — Move on, baad mein revise karo
6. **QUICK-REF.md print kar lo** — Interview ke din kaam aayega
